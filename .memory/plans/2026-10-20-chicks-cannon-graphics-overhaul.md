# Plan: 병아리 대포 카툰 그래픽 전면 개선

## Goal
Canvas 2D 게임 장면을 재질과 입체감이 읽히는 상용 캐주얼 게임풍 카툰 그래픽으로 개선한다. 목재·석재·금속·둥지·알·새총에 벡터 질감과 그림자를 추가하고, 조준 중 병아리를 계속 표시한다. 3단 배경 레이어와 반복 애니메이션, 일시정지/재개 UI, 왼쪽 아래 아이템 트레이를 구현한다. 1280×720 게임 좌표, Matter.js 물리, 4개 챕터와 기존 플레이 규칙은 유지한다.

## Confirmed Decisions
- 아이템 세 버튼은 화면 왼쪽 아래에 둔다. 상단에는 챕터/점수, 탄환, 사운드, 재시작, 일시정지 정보와 조작을 유지한다.
- 조준 가능 상태에서 현재 챕터의 장전된 병아리를 새총에 계속 표시한다.
- 둥지를 플레이 장면에 되돌려 배치하되 장애물과 겹치거나 인접하지 않게 한다. 게임 월드 좌표는 x=360, y=620으로 둔다. 기존 장애물은 x=730 이상이며, 2장 팬 필드의 하단(y=495)과 둥지 상단(y=565)도 분리된다.
- 목재에는 나뭇결/나이테·상단 하이라이트·하단 음영, 석재/철골에는 금속성 그라데이션과 리벳, 새총에는 목재 명암·가죽 밴드, 둥지에는 겹친 짚, 알에는 radial gradient 음영과 반사광을 적용한다.
- 고양이, 블록, 병아리/알 발사체 아래에 `rgba(0, 0, 0, 0.25)` 계열 타원 그림자를 그리고, 블록 모서리에는 접촉 음영을 더한다.
- 배경은 원경/중경/근경으로 구성한다. 노을 안개·불 켜진 창문, 굴뚝 연기·옥상 물탱크·빨랫줄, 녹슨 난간·볼트, 태양 글로우, 새·먼지·반짝임의 반복 애니메이션을 제공한다.
- 일시정지는 물리와 시각 애니메이션을 함께 멈추고, 재개와 현재 챕터 재시작 버튼이 있는 패널을 보여준다.
- UI 글꼴은 Jua를 `@fontsource/jua` 패키지로 앱에 포함한다. 외곽선, 하단 두께, 고대비 아이콘, 텍스트 획/그림자로 팝 아트풍 버튼을 만든다.

## Scope Notes
- 단일 Phase의 순차 Task 네 개로 나눈다. 첫 Task는 기존 렌더러의 정적 오브젝트를 개선하고, 두 번째 Task에서 pause 상태 전이를 먼저 추가한다. 세 번째 Task는 PAUSED 상태를 사용해 애니메이션 시계를 고정한다. 마지막 Task는 HUD 스타일과 폰트만 다룬다.
- 게임 물리 치수, 발사 속도, 피해량, 점수 규칙은 바꾸지 않는다.
- 구현 계획은 현재 React 앱의 `apps/web/src/game/renderer.ts`, Matter.js 엔진, HUD, CSS를 기준으로 한다. 새 Canvas 장면은 기존 `GameCanvasRenderer`에 그리며 별도 렌더러 프레임워크는 추가하지 않는다.
