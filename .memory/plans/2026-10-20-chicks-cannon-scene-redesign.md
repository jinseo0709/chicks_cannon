# Plan: 병아리 대포 장면·HUD 전면 리뉴얼

## Goal
Canvas 게임을 챕터별 정적 테마 장면으로 교체하고, 흐르는 배경을 제거하며, 우측 둥지·연결된 셔터·두꺼운 새총과 구조물, 접지 그림자를 개선한다. 상단 UI를 좌/중/우 한 줄 Flexbox 바로 재배치한다. 모바일에서도 세 구역이 겹치지 않게 하고, 기존 Matter.js 물리 크기와 아이템/점수 규칙은 유지한다.

## Confirmed Decisions
- 좌측 상단에 챕터·점수·탄환, 중앙에 아이템 3개, 우측에 소리·일시정지·재시작을 둔다. 좁은 모바일 화면에서는 아이템 이름을 숨기되 접근 가능한 아이콘 이름을 유지한다.
- 배경의 건물·구름·난간은 정지한다. 챕터 4의 꽃가루/깃털만 애니메이션하며 pause 중 멈추고 재개 시 이어진다.
- 네 챕터는 각각 파스텔 골목 요새, 코랄 선셋 도심 옥상, 퍼플/네이비 폐공장, 골드/민트 초원 축제 팔레트를 갖는다.
- 둥지는 `(1205, 620)`에 약 `130×80`으로 그려 스테이지 4 구조물과 겹치지 않고 1280px 월드 안에 들어오게 한다.
- 블록/요새의 두께는 렌더링만 키운다. Matter.js 충돌 본체와 발사·피해 규칙은 그대로 둔다.
- 새총은 굵은 원목 Y자 기둥, 가죽 파우치, 바닥 받침과 풀숲으로 표현한다. 셔터는 고정 상단 철골 빔의 도르래와 와이어로 연결한다.
- 칙칙한 회색 대신 채도 높은 카툰 색과 밝은 금속 하이라이트를 사용한다.

## Scope Notes

- 기능 규칙, 아이템 수/동작, 점수, 물리 크기, 1280×720 월드 크기는 변경하지 않는다.
