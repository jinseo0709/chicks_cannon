# Decisions: 병아리 대포 게임 화면 개선

- Date: 2026-10-20
- Status: Confirmed

## D01. 도움 아이템 배치
- **Chosen**: 치즈 로켓, 달걀 지진, 거대화 버튼 세 개를 게임 화면 왼쪽 아래로 이동한다.
- **Rationale**: 중앙 상단을 비워 플레이 장면을 더 잘 보이게 한다.

## D02. 발사 전 병아리 표시
- **Chosen**: 조준 중 새총에 장전된 현재 병아리를 항상 그린다.
- **Rationale**: 발사 전에도 조작할 캐릭터와 현재 진화 형태를 알아볼 수 있다.

## D03. 둥지 오브젝트
- **Chosen**: 플레이 화면에 둥지를 다시 배치하되 장애물과 충분히 떨어뜨리고, 짚을 겹쳐 그린 텍스처로 표현한다.
- **Rationale**: 둥지를 장면에 남기면서 장애물과 붙어 보이는 배치를 피한다.

## D04. 배경 그래픽과 애니메이션
- **Chosen**: 원경·중경·근경의 3개 패럴랙스 레이어를 만든다. 원경에는 노을 안개와 작은 불빛 창문, 중경에는 굴뚝 연기·옥상 물탱크·빨랫줄, 근경에는 녹슨 질감과 볼트가 있는 옥상 난간을 둔다. 태양에는 radial gradient와 glow를 적용하고 새·먼지·반짝임 파티클을 애니메이션한다.
- **Rationale**: 장면에 깊이와 움직임을 더해 정적인 실루엣 배경보다 풍성한 카툰 그래픽을 만든다.

## D05. 일시정지
- **Chosen**: 게임 화면에 일시정지 버튼을 추가한다. 누르면 물리와 배경 애니메이션을 멈추고, 재개와 현재 챕터 재시작을 선택할 수 있는 패널을 표시한다.
- **Rationale**: 멈춘 상태와 다음 동작을 명확히 보여주고, 재개 시 같은 장면에서 이어갈 수 있게 한다.

## D06. 목재·금속·캐릭터 그래픽
- **Chosen**: Canvas 2D 렌더링에 상용 캐주얼 게임 수준의 카툰 벡터 디테일을 적용한다. 목재 블록은 나이테와 나뭇결, 베이지색 상단 하이라이트와 어두운 하단 음영을 갖는다. 철골·석재는 메탈릭 그라데이션과 볼트/리벳을 추가한다. 새총은 명암이 있는 나무 기둥과 가죽 질감 밴드로 그리고, 알은 radial gradient 구체 음영과 반사광을 적용한다.
- **Rationale**: 단순한 플랫 도형을 재질과 부피가 읽히는 게임 오브젝트로 개선한다.

## D07. 접지 그림자와 접촉 음영
- **Chosen**: 고양이·블록·발사체 아래에 `ellipse` 기반 반투명 타원 그림자를 그리고, 블록 접촉부에는 가는 어두운 경계 음영을 더한다.
- **Rationale**: 오브젝트가 바닥과 서로 맞닿아 있는 깊이감을 준다.

## D08. HUD 시각 스타일
- **Chosen**: 세 아이템 버튼은 왼쪽 아래에 둔다. 아이템 버튼과 상태창에는 둥근 팝 아트풍 외곽선, 하단 두께가 보이는 3D 효과, 대비가 높은 아이콘을 적용한다. 둥근 캐주얼 게임 폰트와 텍스트 획 또는 그림자로 글자를 선명하게 한다.
- **Rationale**: 기존에 결정한 아이템 위치를 유지하면서 버튼과 정보를 더 선명하고 완성도 있게 표현한다.
